# Privacy Summary

Synapse is a hosted web product.

High-level privacy expectations:

- authenticated users may access and manage their note workspace,
- notes, metadata, and generated outputs may be stored server-side to operate the service,
- configured third-party AI and integration providers may process content as part of supported workflows,
- shared notes or public links expose only the content intentionally published through those features.

This repository does not publish:

- application source code,
- private workspaces,
- infrastructure secrets,
- user credentials,
- integration tokens.
