# Public Roadmap

This is a lightweight public roadmap for Synapse.

## Current product shape

- hosted note workspace
- login and authenticated user access
- rich note editing and quick capture
- list, table, board, tree, graph, and PARA views
- semantic retrieval, AI chat, and summaries
- sharing and external capture flows

## Likely next improvements

- stronger onboarding for first-time knowledge-base setup
- broader screenshot and public demo coverage
- deeper workflow refinement around summaries, concepts, and topics
- smoother integration paths for external capture and downstream use
- more polished collaboration and sharing controls

## Scope note

This roadmap is directional only. It is not a release guarantee.
