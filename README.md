## The Big Shift

Most personal knowledge tools still leave users to solve the hardest part themselves:

- notes pile up faster than structure,
- search depends too much on exact recall,
- ideas stay disconnected,
- AI answers drift because the knowledge base is thin or inconsistent,
- teams and founders keep rewriting insights that already exist somewhere in their notes.

Synapse changes that pattern.

It lets users capture first, then gradually add structure through tags, wikilinks, properties, PARA grouping, semantic search, graph relationships, concept extraction, topic mapping, and AI synthesis.

The "wow" is not only that AI can answer questions.
The "wow" is that notes, relationships, search, and synthesis all operate on the same evolving workspace.

> From scattered notes to a reusable knowledge system.

## Why It Feels Different

1. **Capture** ideas without forcing heavy structure upfront.
2. **Connect** those notes through links, metadata, embeddings, and graph logic.
3. **Synthesize** the growing knowledge base through AI chat, summaries, insights, and topic views.

This repository is a public product-information and support hub for the hosted Synapse product. It does not contain the application source code.

## What You Get

- `Knowledge Workspace` with note creation, editing, templates, and quick capture
- `Multiple Views` across list, table, board, tree, graph, and PARA organization
- `AI Layer` for Rosie chat, note summaries, date-range summaries, and guided synthesis
- `Connected Knowledge` through wikilinks, backlinks, typed relations, concepts, and topics
- `Integrations` for public sharing, API-key inbound capture, Telegram ingestion, and push notifications

## What Synapse Does

- stores notes as the core object in the workspace
- supports fast writing and later organization
- provides several interfaces over the same knowledge base
- uses semantic search and AI retrieval to surface the right notes
- creates summaries, insights, concepts, and topic maps from existing material
- supports controlled sharing and external inbound capture

## Why It Exists

Synapse is not trying to be only a markdown editor or only an AI chat box.

It exists for a more practical problem:

> "People collect useful notes every day, but most systems still make it too hard to turn those notes into a connected, searchable, reusable body of knowledge."

That is why the product sits between PKM, AI retrieval, and structured knowledge work.

## Why People Remember It

- it lets structure emerge after capture instead of before it
- it makes search work by meaning, not only by exact wording
- it gives AI a better working memory through the note base
- it turns one note set into several useful operational views

## Privacy Model

Synapse is a hosted web product.

High-level data behavior:

- authenticated users work inside a note-based knowledge workspace,
- notes, metadata, relations, and generated outputs may be stored server-side to operate the product,
- configured AI and integration providers may process content as part of search, summarization, or workflow execution,
- shared notes or public links only expose the content intentionally published through those features.

See [docs/PRIVACY.md](docs/PRIVACY.md) for the short public privacy summary.
